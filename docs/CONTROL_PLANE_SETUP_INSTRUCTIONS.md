# Control Plane — Infrastructure Setup Instructions for Claude Code

## Context

Set up the control plane test environment on the developer's 
Docker Desktop (macOS). The developer has OTHER projects running 
in Docker already, so we MUST discover and avoid port conflicts.

Read docs/CONTROL_PLANE_ARCHITECTURE.md for the full architecture.

## Rules

- No AI attribution anywhere
- TDD: tests before implementation
- All SQL parameterized (SQLAlchemy ORM)
- All secrets via .env file (never in code, never in docker-compose.yml)
- Document everything in control-plane/README.md
- Automate everything (one command to start, one to stop)
- Free port discovery: do NOT hardcode ports without checking first

## Step 1: Port Discovery (do this FIRST)

Before writing any docker-compose.yml, discover which ports are 
already in use on the developer's machine:

```bash
# Check common ports we might want to use
for port in 5432 5433 9090 9091 9092 8080 8081 8443; do
  lsof -i :$port -sTCP:LISTEN > /dev/null 2>&1 && \
    echo "PORT $port: IN USE" || echo "PORT $port: available"
done

# Also check what Docker containers are already running
docker ps --format "table {{.Names}}\t{{.Ports}}"

# Check docker compose projects
docker compose ls
```

Based on what's available, choose ports for:
- Postgres: prefer 5433 (since 5432 might be used by local Postgres)
- Control Plane API: prefer 9090 (fallback: 9091, 9092)
- Control Plane Dashboard: same port as API (served by FastAPI)

Store the chosen ports in control-plane/.env so everything is 
configurable and nothing is hardcoded.

## Step 4: Create scripts/setup.sh

```bash
#!/usr/bin/env bash
set -euo pipefail

SCRIPT_DIR="$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd)"
PROJECT_DIR="$(dirname "$SCRIPT_DIR")"
cd "$PROJECT_DIR"

echo "=== AI Runtime Monitor — Control Plane Setup ==="
echo ""

# Check prerequisites
echo "[1/6] Checking prerequisites..."
command -v docker >/dev/null 2>&1 || { echo "ERROR: docker not found. Install Docker Desktop."; exit 1; }
command -v docker compose >/dev/null 2>&1 || { echo "ERROR: docker compose not found. Update Docker Desktop."; exit 1; }
docker info >/dev/null 2>&1 || { echo "ERROR: Docker daemon not running. Start Docker Desktop."; exit 1; }

# Discover free ports
echo "[2/6] Discovering available ports..."

find_free_port() {
    local preferred=$1
    local fallbacks="${2:-}"
    if ! lsof -i :"$preferred" -sTCP:LISTEN >/dev/null 2>&1; then
        echo "$preferred"
        return
    fi
    for port in $fallbacks; do
        if ! lsof -i :"$port" -sTCP:LISTEN >/dev/null 2>&1; then
            echo "$port"
            return
        fi
    done
    echo "ERROR: No free port found (tried $preferred $fallbacks)" >&2
    exit 1
}

PG_PORT=$(find_free_port 5433 "5434 5435 5436")
CP_PORT=$(find_free_port 9090 "9091 9092 9093")

echo "  Postgres port: $PG_PORT"
echo "  Control Plane port: $CP_PORT"

# Generate secrets
echo "[3/6] Generating secrets..."
DB_PASSWORD=$(openssl rand -hex 16)
API_KEY=$(openssl rand -hex 24)

# Create .env
echo "[4/6] Creating .env..."
cat > .env <<EOF
# Auto-generated by setup.sh on $(date -u +"%Y-%m-%dT%H:%M:%SZ")
# DO NOT COMMIT THIS FILE

CP_DB_HOST=postgres
CP_DB_PORT=5432
CP_DB_NAME=fleet_monitor
CP_DB_USER=monitor
CP_DB_PASSWORD=$DB_PASSWORD

CP_PORT=$CP_PORT
CP_API_KEY=$API_KEY

POSTGRES_HOST_PORT=$PG_PORT
CP_HOST_PORT=$CP_PORT
EOF

echo "  .env created with random credentials"

# Build and start
echo "[5/6] Building and starting services..."
docker compose build --quiet
docker compose up -d

# Wait for health
echo "[6/6] Waiting for services to be healthy..."
MAX_WAIT=30
WAITED=0
until docker compose exec -T postgres pg_isready -U monitor -q 2>/dev/null; do
    sleep 1
    WAITED=$((WAITED + 1))
    if [ $WAITED -ge $MAX_WAIT ]; then
        echo "ERROR: Postgres did not become ready in ${MAX_WAIT}s"
        docker compose logs postgres
        exit 1
    fi
done

# Run migrations
echo "  Running database migrations..."
docker compose exec -T control-plane python -c "from cp.db import run_migrations; run_migrations()"

echo ""
echo "=== Setup Complete ==="
echo ""
echo "  Fleet Dashboard:  http://localhost:$CP_PORT/dashboard"
echo "  Ingest API:       http://localhost:$CP_PORT/api/v1/ingest"
echo "  Endpoints API:    http://localhost:$CP_PORT/api/v1/endpoints"
echo "  Postgres:         localhost:$PG_PORT (user: monitor)"
echo ""
echo "  API Key: $API_KEY"
echo "  (saved in .env — use this to configure ai-monitor clients)"
echo ""
echo "  Connect your laptop:"
echo "    ai-monitor --start --control-plane http://localhost:$CP_PORT --cp-api-key $API_KEY"
echo ""
echo "  Test client is already running and sending fake data every 30s."
echo "  Check: curl -s http://localhost:$CP_PORT/api/v1/endpoints | python3 -m json.tool"
echo ""
```

## Step 5: Create scripts/teardown.sh

```bash
#!/usr/bin/env bash
set -euo pipefail

SCRIPT_DIR="$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd)"
PROJECT_DIR="$(dirname "$SCRIPT_DIR")"
cd "$PROJECT_DIR"

echo "=== Control Plane Teardown ==="

if [ "${1:-}" = "--wipe" ]; then
    echo "Stopping services and removing all data..."
    docker compose down -v
    echo "Postgres volume deleted."
else
    echo "Stopping services (data preserved in Docker volume)..."
    docker compose down
    echo ""
    echo "Data preserved. To wipe: ./scripts/teardown.sh --wipe"
fi

echo "Done."
```

## Step 6: Create scripts/health-check.sh

```bash
#!/usr/bin/env bash
set -euo pipefail

SCRIPT_DIR="$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd)"
PROJECT_DIR="$(dirname "$SCRIPT_DIR")"
cd "$PROJECT_DIR"

# Load .env
source .env 2>/dev/null || { echo "ERROR: .env not found. Run setup.sh first."; exit 1; }

echo "=== Control Plane Health Check ==="
echo ""

# Check Docker services
echo "[Services]"
docker compose ps --format "table {{.Name}}\t{{.Status}}\t{{.Ports}}"
echo ""

# Check Postgres
echo -n "[Postgres] "
if docker compose exec -T postgres pg_isready -U monitor -q 2>/dev/null; then
    TABLES=$(docker compose exec -T postgres psql -U monitor -d fleet_monitor -tAc \
        "SELECT count(*) FROM information_schema.tables WHERE table_schema='public'" 2>/dev/null)
    echo "healthy ($TABLES tables)"
else
    echo "UNREACHABLE"
fi

# Check CP API
echo -n "[Control Plane API] "
HTTP_CODE=$(curl -s -o /dev/null -w "%{http_code}" "http://localhost:${CP_HOST_PORT}/api/v1/endpoints" \
    -H "X-API-Key: ${CP_API_KEY}" 2>/dev/null || echo "000")
if [ "$HTTP_CODE" = "200" ]; then
    ENDPOINTS=$(curl -s "http://localhost:${CP_HOST_PORT}/api/v1/endpoints" \
        -H "X-API-Key: ${CP_API_KEY}" 2>/dev/null | python3 -c \
        "import sys,json; print(len(json.load(sys.stdin)))" 2>/dev/null || echo "?")
    echo "healthy ($ENDPOINTS endpoints registered)"
else
    echo "UNREACHABLE (HTTP $HTTP_CODE)"
fi

# Check fleet dashboard
echo -n "[Fleet Dashboard] "
DASH_CODE=$(curl -s -o /dev/null -w "%{http_code}" \
    "http://localhost:${CP_HOST_PORT}/dashboard" 2>/dev/null || echo "000")
if [ "$DASH_CODE" = "200" ]; then
    echo "serving at http://localhost:${CP_HOST_PORT}/dashboard"
else
    echo "NOT SERVING (HTTP $DASH_CODE)"
fi

# Check test client
echo -n "[Test Client] "
TC_STATUS=$(docker compose ps test-client --format "{{.Status}}" 2>/dev/null)
if echo "$TC_STATUS" | grep -q "Up"; then
    echo "running ($TC_STATUS)"
else
    echo "NOT RUNNING ($TC_STATUS)"
fi

echo ""
echo "Done."
```

	@echo ""

	@echo "  make teardown   Stop and remove all data"
	@echo "  make health     Health check all services"
	@echo "  make logs       Tail all service logs"
	@echo "  make logs-cp    Tail control plane logs only"
	@echo "  make logs-pg    Tail postgres logs only"
	@echo "  make test       Run CP tests"
	@echo "  make clean      Remove .env, __pycache__, .pyc"
	@echo "  make connect    Show command to connect your laptop"
	@echo ""

setup:
	@bash scripts/setup.sh

start:
	docker compose up -d

stop:
	docker compose down

teardown:
	@bash scripts/teardown.sh --wipe

health:
	@bash scripts/health-check.sh

	docker compose logs -f

	docker compose logs -f control-plane

	docker compose logs -f postgres

	docker compose exec control-plane pytest tests/ -v

	rm -f .env
	find . -type d -name __pycache__ -exec rm -rf {} +
	find . -name "*.pyc" -delete

	@source .env 2>/dev/null && echo "" && \
	echo "Run this on your laptop:" && \

	echo "  ai-monitor --start --control-plane http://localhost:$$CP_HOST_PORT --cp-api-key $$CP_API_KEY" && \
	echo ""

## Step 8: Create docker-compose.yml

Use the .env file for ALL configurable values. No hardcoded 
ports or passwords anywhere in the compose file.

```yaml
services:
  postgres:
    image: postgres:16-alpine
    container_name: arm-cp-postgres
    environment:
      POSTGRES_DB: ${CP_DB_NAME}
      POSTGRES_USER: ${CP_DB_USER}
      POSTGRES_PASSWORD: ${CP_DB_PASSWORD}
    volumes:
      - arm-cp-pgdata:/var/lib/postgresql/data
      - ./migrations/001_initial_schema.sql:/docker-entrypoint-initdb.d/001_schema.sql:ro
    ports:
      - "${POSTGRES_HOST_PORT}:5432"
    healthcheck:
      test: ["CMD-SHELL", "pg_isready -U ${CP_DB_USER}"]
      interval: 5s
      timeout: 5s
      retries: 5
    restart: unless-stopped

  control-plane:
    build:
      context: .
      dockerfile: Dockerfile
    container_name: arm-cp-server
    depends_on:
      postgres:
        condition: service_healthy
    environment:
      DATABASE_URL: postgresql://${CP_DB_USER}:${CP_DB_PASSWORD}@postgres:5432/${CP_DB_NAME}
      CP_API_KEY: ${CP_API_KEY}
      CP_PORT: "9090"
    ports:
      - "${CP_HOST_PORT}:9090"
    restart: unless-stopped

  test-client:
    build:
      context: .
      dockerfile: Dockerfile.test-client
    container_name: arm-cp-test-client
    depends_on:
      - control-plane
    environment:
      CP_URL: http://control-plane:9090
      CP_API_KEY: ${CP_API_KEY}
    restart: unless-stopped

volumes:
  arm-cp-pgdata:
    name: arm-cp-pgdata
```

NOTE: All container names prefixed with "arm-cp-" (AI Runtime 
Monitor Control Plane) to avoid conflicts with other Docker projects.
Volume name is explicit to avoid anonymous volume conflicts.

## What NOT to do

- Do NOT hardcode port 5432 or 9090 anywhere in docker-compose.yml
  — always use ${VARIABLE} from .env
- Do NOT put passwords in docker-compose.yml — always ${CP_DB_PASSWORD}
- Do NOT use default Docker volume names — prefix with arm-cp-
- Do NOT use default container names — prefix with arm-cp-
- Do NOT assume ports are free — setup.sh checks first
- Do NOT require manual steps — everything via make targets
- Do NOT commit .env — only .env.example
- Do NOT use root user in Dockerfile — add a non-root user
- Do NOT expose Postgres to 0.0.0.0 — bind to 127.0.0.1 via 
  ports: "127.0.0.1:${POSTGRES_HOST_PORT}:5432"
